========================================================================
   KD CREATION 4K CINEMA & LUXURY WEDDING WEBSITE - SETUP GUIDE
========================================================================

આ પ્રોજેક્ટ કોઈપણ કમ્પ્યુટર (Windows / Mac / Linux) પર ચલાવવાની સરળ રીત:

------------------------------------------------------------------------
📌 જરૂરિયાત (PREREQUISITES):
------------------------------------------------------------------------
1. તમારા કમ્પ્યુટરમાં Node.js ઈન્સ્ટોલ હોવું જોઈએ (Node.js 18 કે તેથી નવું).
   જો ઈન્સ્ટોલ ન હોય તો https://nodejs.org/ માંથી ડાઉનલોડ કરી ઈન્સ્ટોલ કરો.

------------------------------------------------------------------------
🛠️ ચલાવવાના 3 સરળ સ્ટેપ (STEP-BY-STEP RUN GUIDE FOR BEGINNERS):
------------------------------------------------------------------------

સ્ટેપ 1: Terminal / Command Prompt ઓપન કરો
  - Windows: આ ફોલ્ડરમાં જઈને ઉપર સરનામા પટ્ટીમાં 'cmd' લખી Enter દબાવો.
  - Mac: આ ફોલ્ડર પર રાઈટ-ક્લિક કરીને 'Open in Terminal' પસંદ કરો.

સ્ટેપ 2: લાઇબ્રેરીઓ ઈન્સ્ટોલ કરો (ફક્ત પહેલી વાર)
  Terminal માં આ કમાન્ડ લખીને Enter દબાવો:
  
      npm install

સ્ટેપ 3: સાઈટ લોકલ ચાલુ કરો
  Terminal માં આ કમાન્ડ લખીને Enter દબાવો:
  
      npm run dev

  👉 સાઈટ તમારા બ્રાઉઝરમાં ચાલુ થઈ જશે:
      http://localhost:3000/

------------------------------------------------------------------------
🌐 પ્રોડક્શન બિલ્ડ અથવા હોસ્ટિંગ માટે (FOR BUILDING & DEPLOYMENT):
------------------------------------------------------------------------
  નવી Dist ફાઈલો બનાવવા માટે:
      npm run build

  GitHub Pages પર પબ્લિશ કરવા માટે:
      npm run deploy

------------------------------------------------------------------------
🔑 સિક્રેટ એડમિન એક્સેસ (SECRET ADMIN ACCESS):
------------------------------------------------------------------------
  લાઈવ અથવા લોકલ સાઈટ ઓપન કર્યા પછી:
  Keyboard શોર્ટકટ: Ctrl + Shift + A (અથવા Mac પર Cmd + Shift + A) દબાવો.
  આનાથી ગુપ્ત એડમિન લોગિન અને લીડ પોર્ટલ ઓપન થશે.
